# Этап 7: ознакомление с ЛНА и простая электронная подпись

## Объём

Реализованы требования FR110, FR115, FR220, UC020 и UC090 без расширения на этапы 8+.

- сотрудник ОК создаёт лист для всей организации, подразделения, должности или списка сотрудников;
- перед созданием можно посмотреть состав аудитории и количество участников;
- лист создаётся только для подписанного документа;
- сотруднику показываются документ, срок, чекбокс подтверждения и учебный код простой ЭП;
- код генерируется `SignatureService`, а при подтверждении сохраняется в `acquaintance_mark.signature_data` вместе с датой;
- повторное подтверждение уже выполненной отметки запрещено;
- карточка листа показывает количество и процент ознакомившихся;
- список не ознакомившихся выгружается в UTF-8 CSV.

## Прикладной слой

Основная логика находится в `AcquaintanceService`, web-маршруты — в
`AcquaintanceController`. Используются существующие `AcquaintanceSheetEntity`,
`AcquaintanceMarkEntity`, репозитории и ограничения БД, включая уникальность
пары лист/сотрудник. `SignatureService` не имитирует внешний SMS-шлюз:
сгенерированный код намеренно выводится в интерфейсе учебного прототипа.

## Проверка

Добавлены модульные тесты на запрет листа для неподписанного документа и
одноразовую фиксацию ознакомления с данными подписи. Проверка выполняется
командой:

```text
gradlew.bat test --no-daemon
```
