# Этап 4. Работа с документами

## Что сделано

PR закрывает этап 4 плана разработки ИС КЭДО:
работу с кадровыми документами и вложениями.

Соответствие расчётно-пояснительной записке:
таблица 2.2 (FR030, FR040, FR150, FR160, FR200),
требования FR210 и UC110.

## Реализованные сценарии

### Реестр документов

- поиск по номеру или названию;
- фильтры по виду документа, статусу и периоду создания;
- ограничение видимости документами автора и участниками маршрута;
- переход к карточке документа.

### Создание документа

- выбор активного вида документа;
- полная форма создаётся по JSON-шаблону `template_json`;
- предзаполнение реквизитов пользователя предусмотрено в прикладной модели;
- обязательные поля проверяются на сервере;
- дата окончания отпуска не может быть раньше даты начала;
- документ создаётся в статусе `DRAFT`.

### Карточка и редактирование

- номер документа, вид, автор, дата создания и поля в формате JSON;
- редактирование доступно только автору и только в статусах
  `DRAFT` или `REWORK`;
- подписанный или отправленный документ не редактируется;
- отзыв доступен только для документа в статусе `IN_APPROVAL`.

### Вложения

- ограничение 25 МБ на один файл;
- суммарный лимит 100 МБ на документ;
- запрет исполняемых файлов и скриптов;
- сохранение файла в каталоге вложений;
- загрузка доступна только автору документа в редактируемом статусе.

## Проверка

- `./gradlew.bat test --offline` — сборка и тесты проходят;
- добавлены модульные тесты валидации шаблона документа,
  создания черновика, запрета отзыва черновика и запрета редактирования
  подписанного документа.
