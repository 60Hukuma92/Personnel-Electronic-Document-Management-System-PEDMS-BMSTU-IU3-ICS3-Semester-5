# Этап 11 — тестирование и документация

## Описание

Этап завершает технологическую часть НИРС и документацию технического задания ИС КЭДО.

В рамках этапа:

- приведён в рабочее состояние набор модульных тестов JUnit 5 прикладных сервисов;
- добавлен интеграционный тест Spring Data JPA на тестовой схеме H2 в PostgreSQL-режиме;
- добавлена опциональная проверка реального PostgreSQL с отдельными переменными тестового подключения;
- production-конфигурация остаётся без `ddl-auto=create` или иного автоматического изменения схемы;
- подготовлен протокол тестирования функциональных, технических и БД-требований;
- создан русскоязычный `README.md` со сборкой, запуском и настройкой Supabase;
- добавлено краткое руководство для сотрудника, руководителя, HR и администратора;
- дополнены описания архитектуры и структуры базы данных;
- актуализирована документация этапа для включения в расчётно-пояснительную записку.

## Проверка

```powershell
.\gradlew.bat clean test
.\gradlew.bat bootJar
```
