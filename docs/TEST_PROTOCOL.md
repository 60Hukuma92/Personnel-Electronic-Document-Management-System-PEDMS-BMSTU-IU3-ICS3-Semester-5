## Общий вывод

Фактический запуск `./gradlew.bat clean test bootJar --no-daemon` завершился успешно. Набор содержит 32 теста; 31 выполнен и 1 тест реального PostgreSQL пропущен, поскольку переменная `PEDMS_TEST_DB_URL` не задана. Сбоев нет. Интеграционный тест реального PostgreSQL является отдельной опцией: отсутствие тестовой БД не ослабляет production-конфигурацию и не запускает изменение рабочей схемы.
